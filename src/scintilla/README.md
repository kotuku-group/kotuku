# Scintilla lexer configuration

The Scintilla module exposes its configured lexer profiles through `SupportedLexers`. All public profiles are enabled
by default. Disable individual profiles at CMake configure time, for example:

```powershell
cmake --preset agents-platform -DSCINTILLA_LEXER_PYTHON=OFF -DSCINTILLA_LEXER_RUBY=OFF
cmake --build --preset agents-platform-install
```

Use `SCINTILLA_LEXER_<ID>` with the public profile ID from `lexer_config.cmake`. Set an option back to `ON` to restore
it. The `NIL` profile is always included for plain text. The configuration generates both the public profile list and
the private Lexilla catalogue, and compiles only the required lexer source files. Profiles that share a factory or a
source file retain it until no enabled profile needs it; consequently, disabling a single profile does not necessarily
remove its implementation from the binary. Automatic file-type detection skips disabled profiles, and explicitly
selecting one returns `ERR::NoSupport`.

The catalogue is generated in the build tree from the vendored Lexilla source. When updating Lexilla, preserve its
two autogenerated catalogue markers, and check the mappings in `lexer_config.cmake` against the updated lexer modules.
